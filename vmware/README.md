# Running MicroOS on VMware Workstation

This directory contains the virtual machine configuration (`micro_os.vmx`) to boot MicroOS in **VMware Workstation Pro**, **VMware Workstation Player**, or **VMware Fusion**.

---

## Prerequisites

1. **VMware Workstation Pro / Player** (version 15, 16, or 17).
2. The packaged VMDK disks generated by the build pipeline:
   - `build/micro_os.vmdk` (Kernel + Bootloader BIOS MBR disk)
   - `build/data.vmdk` (4 MiB MicroFS persistent data disk)

---

## Quick Start: Step-by-Step

### 1. Build and Package the VMDK Disks
From the repository root, run the packaging script:
```powershell
.\scripts\package.ps1
```
This script runs `cargo bootimage` and converts the raw disk images to VMware VMDK format using `qemu-img`.

### 2. Open the VM in VMware Workstation
1. Launch VMware Workstation.
2. Click **File** -> **Open...** (or press `Ctrl+O`).
3. Navigate to `vmware\micro_os.vmx` and select **Open**.
4. If prompted with *"This virtual machine might have been moved or copied"*, choose **"I copied it"**.

### 3. Power On the Virtual Machine
1. Click **Power on this virtual machine** (green play button).
2. The BIOS will boot `micro_os.vmdk` via the Primary IDE Master channel.
3. MicroOS will detect the Primary Slave data disk (`data.vmdk`), mount the MicroFS filesystem, calibrate the CPU clock, and launch the interactive shell:
   ```text
   ==================================================
      MicroOS v0.5 - Async Kernel & Interactive Shell
   ==================================================
   Kernel booted successfully!
   Serial port online.
   ATA Primary Slave hard drive detected (8192 sectors, ~4 MiB)
   MicroFS superblock mounted successfully.
   Boot time to shell: 123.729 ms (calibrated @ 2510 MHz)
   micro_os:/> 
   ```

## Virtual Hardware Configuration Details

| Component | Setting | Reason |
|---|---|---|
| **Guest OS** | `other-64` (Other 64-bit) | Standard x86_64 CPU mode without Linux-specific assumptions |
| **Memory** | 512 MB | Generous headroom for kernel heap, frame allocator, and block buffers |
| **CPU** | 1 vCPU | Single-core mode matching cooperative async runtime |
| **Boot Disk (ide0:0)** | `build\micro_os.vmdk` | Primary IDE Master; MBR bootloader stage 1/2 loads ELF kernel |
| **Data Disk (ide0:1)** | `build\data.vmdk` | Primary IDE Slave; formatted with MicroFS on-disk filesystem |
| **Serial Port (serial0)** | `serial.log` | UART 16550 serial output mirrored to file for debugging |
| **NIC (ethernet0)** | `e1000` (Intel 82540EM) | Standard PCI Gigabit Ethernet controller for Phase 6 LAN networking |

## Verifying in QEMU First
Before loading into VMware, you can verify that the exact VMDK files boot cleanly using:
```powershell
.\scripts\run_vmdk.ps1
```
This launches QEMU using the exact same virtual IDE master/slave disk architecture as VMware.
